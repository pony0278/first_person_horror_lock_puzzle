## 判定門檻

**阻擋 F0 驗收**（不修就別找 5~8 人測）：
- 2.1 任一機種主觀 ≤ 2 分，或 2.6 明顯熱節流
- 5.1~5.4 任一項在真機上「按不準」
- 6.3~6.5 任一項黑畫面不恢復
- 7.6 修正後在真機上仍然分不出撞針高度差

**記入 F0.1，不阻擋**：
- 4.2、4.3（設計文件 §9 已保證靜音可玩）
- 3.x safe-area 相關（醜但可玩）
- 8.x 直向（F0 範圍本來就是橫向）

**加分觀察**：7.4、7.5 —— 這兩項會直接影響驗收標準 #1 和 #2 的解讀。
